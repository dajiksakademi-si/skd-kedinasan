Setiap kali Gusti memberi aturan baru, mengoreksi aturan lama, atau memutuskan sesuatu, catat saat itu juga: (1) file memory terkait + baris MEMORY.md, (2) log tugas aktif (mis. riset/2026-10-30-log-handbook-tiu.md), (3) `memory.md` di root project. Aturan yang berlaku lintas tugas juga masuk reference skill (aturan-tetap.md / reference subtes) lalu `cek.py`.

**Why:** Gusti 2026-10-30, saat mengizinkan perbaikan engine TIU v0.4.1: "selalu catat keterbaruan rules gusti ini". Aturan Gusti terus bertambah (diksi, judul, desain); yang tidak tercatat hilang saat /compact atau sesi baru.

**How to apply:** catat sebelum lanjut ke langkah berikutnya, dengan tanggal dan kutipan singkat kata Gusti. Tulis sebagai aturan yang bisa dipakai ulang, bukan cerita. Terkait [[feedback-belajar-per-tahap]], [[feedback-wording-handbook]], [[skd-handbook-tiu]].
